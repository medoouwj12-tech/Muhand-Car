A luxury, high-converting automotive rental web application for **Muhand Car** (مكتب مهند كار لإيجار السيارات) in Minya, Egypt. Built with Next.js (App Router), Tailwind CSS, Framer Motion, and Lucide Icons.

---

## ✨ Features

- 🌟 **Luxury Dark & Gold Aesthetic**: Deep obsidian background with gold accents, glowing borders, and glassmorphism.
- 🌓 **Dark & Light Mode**: Instant theme switching in the navbar.
- 🌐 **Multi-Language (i18n)**: Arabic (RTL) & English (LTR) with instant language toggle.
- 🚘 **Interactive Multi-Image Car Fleet Gallery**:
  - Filterable categories (Wedding, VIP Luxury, Travel & Airport, SUVs, All).
  - Multi-image carousel slider with fullscreen lightbox modal preview for each car.
- 📱 **Direct WhatsApp Booking Engine**:
  - Form formats structured reservation details directly to WhatsApp **`+201003829853`** (`01003829853`).
  - Floating WhatsApp action widget with quick-start conversation options.
- 📍 **Minya Location & Google Maps**:
  - Embedded Google Map with Plus Code: `3Q9H+J5V, Qism Minya, Minya Governorate 2426770`.
  - Contact cards, 24/7 working hours, and direct calling.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/medoouwj12-tech/Muhand-Car.git
cd Muhand-Car
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
npm run start
```
